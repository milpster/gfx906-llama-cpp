  Build A = build-e106a-gdn (kept). Baseline re-run first (E106-B0):
  pp 374.7 / fill 250.1 / tg 12.2 / acc .658 / sha e54019ff - note ~+9-16%

  'K=1 n_tokens=384 S_v=128 H=48 stride=0' - kernel ENGAGES, 0 keep_rs
  plain calls. So: engaged + bit-identical + perf-neutral. Why neutral:
  base kernel already keeps state in registers across the token loop (one
  launch per ubatch either way); the chunk variant's real change is Tc
  columns per warp (2 for S_v=128) halving q/k shard loads, but the op is
  compute-dominated (S_v^2=16384 MAC/token/head vs 2x128 loads) and the
  DPP xor-butterfly (offsets 1,2,4,8,16,32) matches the shfl_xor tree's
  add order -> bit-identical. mx's gain case must be KDA/other-S_v models.
  VERDICT: no production win on this model; code kept in-tree (bit-exact,
  zero-risk) but not counted as a win. PPL gate skipped: sha-identical.
