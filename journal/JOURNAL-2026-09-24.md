## E185 - q4v native tile: ROOT CAUSE FOUND AND FIXED (kernel now correct)

### Root cause
ggml q4_0 packs 32 values per block with a NIBBLE-SPLIT layout: byte l's low
nibble is element l and its high nibble is element l+16 (ggml-quants.c
dequantize_row_q4_0). My loader used the dequantize.cuh `dequantize_q4_0`
helper which pairs (low, high) of byte l as elements (2l, 2l+1). That pairing
is fine inside vecdot kernels (the q8 side there is accessed with the same
split convention and dot products are permutation-invariant) but wrong for
standalone element placement. Symptom fingerprint: gpu_out[2k] = ref[k],
gpu_out[2k+1] = ref[k+16] per 32-value block - every row-sum checksum
matched because sums are permutation-invariant within a row.

### Why the debug took so long (recorded so future sessions skip this)
- test FA tensors are seeded from std::random_device per process
  (init_tensor_uniform / init_tensor_kq_mask) - cross-process dump
  comparisons were comparing different data. Fixed temporarily with a
  pinned seed, reverted after.
- Unsynchronized legacy-stream cudaMemcpy in host dumps read STALE pre-kernel
  pool bytes that happened to be identical across modes - false "outputs
  identical" conclusion. cudaDeviceSynchronize() before dumping exposed the
  real (partials-like scrambled) output. The comparison callback reads the
  true final tensor; always dump from there or after a device sync.
- "Two kernel launches" was a misread: 8 dump lines = one execution, two
  chunks (kV=0 + oob tail kV=960).

### Fix
fattn-tile.cuh flash_attn_tile_load_tile_q4_0 (both half2 and float
overloads): explicit nibble math per block, half2[l] = (low(2l), low(2l+1)),
half2[8+l] = (high(2l), high(2l+1)); one-line comment records the layout
invariant. No dequantize.cuh helper use.

### Verification
- force_native mixed q8_0/q4_0: 1/1 PASS on hs=64 kv=1024 nb=32 (the
  previously failing case, ERR 1.8-1.9 before).
- Full FLASH_ATTN_EXT suite with force_native: 3994/3994 PASS (3982 old +
  12 new mixed prefill variants; the mixed-pair case line stays in the
  prefill loop as permanent coverage for the native path).
- AUTO (no env): 13/13 mixed cases PASS; graphs on/off identical.
- llama-server rebuilt clean; no diagnostics remain (grep DBG clean).

1. scattered 2B global loads (one thread per 34B block, qs ushorts at 34B stride)
